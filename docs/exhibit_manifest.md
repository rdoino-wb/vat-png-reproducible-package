## Notes

The table above lists every exhibit produced by code in this package. Exhibits in the manuscript that do not appear here (for example a descriptive Table 1 or Table A1, or appendix figures in gaps such as A8, A9, A16) are not generated by this code; they are built by hand or excluded by design.

Figure filenames do not always match the exhibit number in the paper (for example Figure 4d exports to the `event_study/` subfolder). This table gives the exact mapping so a reviewer can match each output to the manuscript.
